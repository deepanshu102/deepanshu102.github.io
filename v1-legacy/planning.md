# Planning & Roadmap: Portfolio v2.0

## Overview
A high-impact, futuristic 3D portfolio themed around "Deep System Architecture." Designed for zero-build-tool deployment on GitHub Pages.

## Build Phases

### Phase 1: 3D Scene Foundation (8–10h)
*Goal: Establish core visual language.*
- [ ] Initialize Three.js particle field (Hero network metaphor).
- [ ] Implement SVG/CSS circuit-board background trace lines.
- [ ] Setup Hero layout with 3D perspective tilt.
- [ ] Build custom glowing cursor and IntersectionObserver reveal system.

### Phase 2: Content Sections (10–12h)
*Goal: Data migration and futuristic UI components.*
- [ ] **About:** Holographic card with gyroscope parallax.
- [ ] **Experience:** Terminal-style typewriter timeline (Coforge, Ascendion, etc.).
- [ ] **Projects:** 3D card flip grid (Jobseekers-Stops, Banking, etc.).
- [ ] **Skills:** SVG animated radar/hexagon visualization.

### Phase 3: Visual FX & Polish (8–10h)
*Goal: Premium "Tron Legacy" aesthetic.*
- [ ] CSS variable-based Neon Glow system.
- [ ] Scroll-linked parallax layers (3 depth levels).
- [ ] Hover micro-interactions (shimmers, draw-lines).
- [ ] Boot-up terminal sequence loading screen.

### Phase 4: Freelance CTAs & Contact (4–5h)
*Goal: Conversion optimization.*
- [ ] "Available for hire" pulsing status badge.
- [ ] Futuristic Contact UI with mailto/social links.
- [ ] Floating glowing action button.

### Phase 5: Responsive & Deployment (5–6h)
*Goal: Stability and launch.*
- [ ] Mobile fallback (disable WebGL on touch devices).
- [ ] Performance optimization (Lazy-loading, particle reduction).
- [ ] GitHub Pages deployment and final QA.
