# Tech Stack

## Frontend Core
- **HTML5/CSS3:** Semantic tags and modern CSS (Variables, Grid, Flexbox, Perspective).
- **Vanilla JavaScript:** ES6 modules where appropriate, no frameworks.

## Libraries (CDN Only)
- **Three.js:** 3D engine for hero particle network.
- **GSAP (GreenSock):** For scroll-triggered animations and complex sequencing.
- **Google Fonts:** For `Orbitron` and `JetBrains Mono`.

## Tools
- **GitHub Pages:** For hosting.
- **LibreOffice Calc (Context):** Used for financial/data tracking (referenced for logic/formulas).
- **macOS:** Primary development environment.
